# Betz-Gesetz & Auftriebsläufer – interaktives Lehr-Dashboard

Streamlit-App für die Lehre (Energiesysteme, THI):

- **Betz-Gesetz:** v₂ bei gegebenem v₁ einstellen, animierte Stromröhre, c_P-Kurve, Energiebilanz, Herleitung
- **Auftriebsläufer:** Geschwindigkeitsdreieck am Blattschnitt, Auftrieb/Widerstand, Profilpolare, Vergleich mit Widerstandsläufer

Deutsch / English umschaltbar.

## Lokal starten

```bash
pip install -r requirements.txt
streamlit run app.py
```
